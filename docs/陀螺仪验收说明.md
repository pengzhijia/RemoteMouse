# 鼠标 / 陀螺仪验收版

两种控制模式：鼠标（系统遥控器触控区移动光标）和陀螺仪（手机运动数据移动光标，触控区继续执行点击/手势）。电脑控制区统一显示触摸布局。

## Mac 验收

1. 安装新 DMG，退出旧版本，启动当前 TVRemoteMouse；需要为当前签名版本授予辅助功能。
2. 保持手机电脑同一局域网。在状态栏或控制台选择“陀螺仪”，点击“连接 iPhone 陀螺仪”，扫描二维码或复制地址至 iPhone Safari。
3. 采集地址为本机 HTTPS 19443，使用生成的本地自签名证书。浏览器可能要求确认信任；若 Safari 仍拒绝运动权限，需要先解决证书信任。本包没有自动给手机安装证书。
4. 在手机页面点击“开启陀螺仪”，允许运动权限，转动手机观察鼠标。用暂停按钮调整握姿；灵敏度和横纵轴可在采集页调整，默认横 gamma、纵 alpha。
5. 切回“鼠标”后运动数据不应控制光标，系统遥控器单指移动恢复。
6. 编辑 PIN、设备连接、按键映射等继续使用原控制台。

## 触控采集页

补充的手机触控页使用真实 Touch Events：单指轻点左键，双指轻点右键，三/四指轻点执行配置动作；双指移动滚动，捏合分级调用缩放快捷键，三指滑动按住左键拖动物体、抬起释放，四指滑动调用桌面/调度中心快捷键。它不是虚拟 Magic Trackpad，不提供原生连续缩放/旋转，三指拖动在断连或后台时自动释放左键。

系统 Apple TV 遥控器入口保留。原生遥控器是否发送独立多指数据的限制仍存在，补充网页不会改变系统遥控器的报文。

## 必须验证的限制

- 陀螺仪数据来自手机 Safari 采集页，不来自 Companion Link。切到控制中心系统遥控器、其他应用或锁屏时采样可能暂停，不能保证“陀螺仪持续移动＋系统遥控器手势”同时成立。
- 接收端采用 TLS、独立随机会话令牌、请求大小/时限限制和位移上限；运动停止后不持续预测移动。手机恢复采样时限制时间步长，避免大跳。
- 当前仅完成编译、接收端 TLS/令牌/输入接口验证；运动权限、手机传感器轴向、操作手感及并行状态需用户真机验收。
- Windows 同步采用鼠标/陀螺仪和触摸布局；从托盘复制运动采集地址到手机，允许新核心程序通过专用网络防火墙。Windows 版本未实机测试。

## 本轮修复

- 触控报文路径同步更新会话就绪计数，避免能够操作却显示连接中；重复开始事件不会重复计数。
- 本地地址优先选择物理局域网，避免二维码指向代理 TUN 网卡。
- 运动采集页打开和收到陀螺仪样本写入日志，便于区分网络未连接、传感器未开启和电脑未选陀螺仪模式。
