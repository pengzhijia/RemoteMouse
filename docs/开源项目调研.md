# 触控板与姿态鼠标：开源项目调研

调研日期：2026-11-09。查阅仓库说明、许可证和以下源码；未在 iPhone 上安装运行这些项目，不把仓库作者宣称等同于本项目实测。

## 结论

存在可复用的多指识别、平滑滚动、陀螺仪鼠标代码。但本轮未找到经验证可仅使用 iPhone 控制中心 Apple TV 遥控器，同时输出独立多指轨迹和手机陀螺仪数据的完整开源实现。

应保持现有 RemoteMouse 的协议研究路线，将输入采集、手势识别、桌面事件输出分别验证。下列代码可以减少后两项工作，不能替系统遥控器制造没有收到的数据。是否增加手机网页/客户端取决于用户对入口的选择。

## PadRemote：优先参考手势识别

- 仓库：https://github.com/padremote/padremote
- MIT；macOS 主机＋手机浏览器，非系统遥控器。
- 已检查 `desktop/src/gesture/mod.rs`、`desktop/src/input/macos.rs`、`web/src/gestures.ts`、`docs/user/gestures.md`。
- 实现多触点状态跟踪、轻点、长按拖动、双指滚动、惯性、三四指滑动和多指捏合的判别。部分缩放功能在 Advanced 且默认关闭。
- Rust 手势核心与现工程技术接近。可参考触点逐步落下、取消、滚动与捏合冲突、误触抑制等处理。
- Mac 输出有连续滚动/滚动阶段/惯性阶段字段。部分缩放和桌面功能使用快捷键，不是完整虚拟 Magic Trackpad。
- 当前 README 明确 macOS only，Windows 尚未支持；接入本项目须复用自己的 Windows 输出层。
- README 目前说明无线链路没有 TLS，复用算法时不能照搬网络设计替换本项目配对加密。

## MOUSENDECK：优先参考陀螺仪鼠标

- 仓库：https://github.com/kode2025/MOUSENDECK
- MIT；Mac＋手机 HTTPS 网页/PWA，非系统遥控器，当前没有 Windows 主机。
- 已检查 `public/app.js` 中 `onMotion`、`captureAxis`、运动授权、触控识别和 `host/native/mdinput.swift`。
- 陀螺仪来自 `DeviceMotionEvent.rotationRate`，包括设备轴校准、静止死区、按 dt 积分角速度转为鼠标增量、dt 上限防止恢复后光标大跳、灵敏度设置。
- 包含触控轻点/拖动/滚动、三四指滑动及快捷键动作。
- 有实际实现代码，可参考算法；不能据此认定切到系统 Apple TV 遥控器后网页仍可持续供应陀螺仪。README 也将 Page Visibility 用于后台暂停。
- README 中延迟数字、平台限制和原生手势不可实现等说法均为作者环境下的结论，未在本项目验证，不照单全收。

## Entangle：参考独立手机客户端与协议拆分

- 仓库：https://github.com/gabrieldonadel/entangle
- MIT；手机 React Native / Expo＋Mac 客户端，非系统遥控器。
- 已检查 `apps/mobile/src/features/trackpad/gestures.ts`、`TrackpadSurface.tsx` 和 README。
- 实现单指移动、点击、长按拖动、双指滚动、右键手势，亦有三指滑动识别代码。
- 适合参考移动端识别和输入消息组织；本轮未验证陀螺仪功能。README 的 Windows 桌面端仍在 roadmap。

## remote-me：参考 Companion 新旧协议

- 仓库：https://github.com/jxgedouard/remote-me
- MIT；用于客户端控制 Apple TV / LG TV，方向与我们的“伪装接收端”不同。
- 已检查 `docs/apple-remote-protocol.md` 和 `backend/companion/client.js`。
- 包含新版 `HIDTouchStart/HIDTouch/HIDTouchStop` 和旧 `_touchStart/_hidT` 的线索及不同 phase 取值，适合补接收兼容与实验。
- 实际发送代码仍固定 `TouchFinger: 1` / `_tFg: 1`。不能当成多指轨迹或陀螺仪已经打通的证据。
- 逆向说明非 Apple 官方协议保证，必须对照真实手机/系统采集验证。

## 现有工程上游

https://github.com/corvofeng/atv-core 本身就是本地工程的基础路线：以系统 Apple TV 遥控器控制电脑。其公开功能包含单指触控/点击和按键，没有在本轮发现能解决独立多指轨迹或手机陀螺仪的已验证实现。

## 备选旧原生姿态示例

https://github.com/ascarrambad/gyromouse：MIT。README 明确为旧的、未维护 Swift 3.x iOS 应用，声称支持转动移动光标、倾斜滚动、摇动校准。本轮只核对仓库说明，未审计源码；不建议直接作为当前主工程基础。

## 复用顺序

1. 原生遥控器入口：研究 remote-me 新旧事件兼容，继续获取真实手机触点证据。
2. 获得多指数据后：评估移植 PadRemote 的 Rust 手势识别和连续滚动输出，保持 Swift 主程序的辅助功能授权与输入转发。
3. 获得运动数据后：借鉴 MOUSENDECK 的校准、死区、恢复保护；原生采集使用 Core Motion 时可采用融合姿态。
4. 若必须新增手机采集端：再评估网页或独立客户端；提前验证与控制中心遥控器并行时的采样限制。
5. 引入代码前固定具体提交、保留 MIT 版权/许可证、检查依赖许可并执行本项目测试。本次未将第三方源码合并进应用。

只读源码快照保存在 `build/research/`，不参与正式构建，也不作为稳定的上游版本锁定。
