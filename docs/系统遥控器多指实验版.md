# 仅系统遥控器：多指实验版

本版只使用 iPhone 控制中心的 Apple TV 遥控器。默认不启动 Safari 运动采集服务，也不使用独立手机应用。启动时恢复鼠标输入来源，避免旧陀螺仪偏好屏蔽单指鼠标。

## 已实现的接收端功能

- 同时解析 Rapport `_hidT` 与 TVRemoteCore `HIDTouch` 字段；两组 phase 编号分别转换，取消事件不触发轻点。
- 独立触点按不同颜色显示原始坐标；Mac 显示当前触点数与本次最多触点数。
- 收到两个独立触点移动时滚动；三个独立触点移动时按住左键拖动，抬起或断连释放；三、四指轻点调用原映射。
- 重复 begin 不产生额外触点。没有第二触点时不伪造双指轨迹。
- 日志中的 `[native-input]` 保存触控、HID、手势和运动事件的名称、内容及可复解码 OPACK 十六进制；不记录配对密钥或键盘文字内容。

## 尚未证明的部分

当前真实 iPhone 报文仍仅观察到一组触点。上述接收端功能通过合成报文测试，不代表系统遥控器已确认会发出双、三、四指数据。没有发现可以可靠启用多指或陀螺仪的能力开关，因此没有编造协商标志，也没有将此包标为多指验收完成。

陀螺仪暂显示未收到数据并禁用切换；本版不提供 Safari 替代入口。

## 测试顺序

退出旧版，启动本版，确认当前版本有辅助功能权限。在控制台清空轨迹后，只使用控制中心系统遥控器：

1. 单指滑动两次，确认光标和轨迹正常、状态栏变绿。
2. 双指上下滑动三次，间隔 2 秒，记录最多触点数及是否滚动。
3. 三指拖动三次，记录最多触点数及是否拖动。
4. 三指、四指分别轻点三次，间隔 2 秒，查看对应映射是否触发。

每组完成后告知组名，我读取本机日志对照。无需扫码或打开 Safari。
